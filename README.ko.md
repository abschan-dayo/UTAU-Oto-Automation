# UTAU 원음 설정 자동화 도구 (Autoto)

> 이 문서는 AI를 사용해 번역했습니다. 일본어 원문은 [README.md](README.md)에서 확인할 수 있습니다.

언어: [日本語](README.md) | [English](README.en.md) | 한국어

### &lt;이 원음 설정 추정 소프트웨어는 현재 연속음 전용입니다.&gt;

WAV 파일에서 UTAU 음원의 원음 설정을 자동으로 추정합니다. 추정 결과는 음원 폴더의 `oto.ini`에 저장됩니다.

## 생성된 원음 설정의 크레딧

본 소프트웨어로 생성한 `oto.ini`를 **수정 없이 그대로** 공개하거나 배포하는 경우, 원음 설정 추정에 사용한 소프트웨어가 **“Autoto (개발: ふっきんちゃん)”**임을 크레딧에 반드시 명시해야 합니다.
생성 결과를 바탕으로 원음 설정을 편집하는 경우 크레딧 표시는 선택 사항이지만, 이 경우에도 같은 크레딧을 기재해 주시면 감사하겠습니다.

## 알고리즘 개요

Autoto는 WAV 파일과 파일명에 적힌 가나 문자열을 단서로 삼아 세 가지 방법으로 원음 설정을 추정합니다. 음량, 스펙트럼, 주기성, 기본 주파수 등의 음향 특징을 분석하고, 소리가 이어지는 순서에 따라 경계가 될 만한 지점을 찾습니다.

1. **스펙트럼·음량 분석**: 스펙트럼과 음량 등의 변화를 바탕으로 발음 시작점과 모음이 안정되는 위치를 찾습니다.
2. **스펙트로그램 이미지 인식**: CNN으로 스펙트로그램을 분석하고 학습된 경계 패턴을 바탕으로 선행 발성 위치를 추정합니다.
3. **음소 위치 분석**: 음향 특징을 음소 배열과 대조하여 각 음소의 위치를 추정하고 원음 설정의 경계를 결정합니다.

사용할 분석 방법을 선택할 수 있습니다. 여러 방법을 선택한 경우에도 중앙값을 사용하는 항목은 선행 발성 추정값뿐입니다. 오프셋, 오버랩, 자음부, 오른쪽 블랭크 등 나머지 `oto.ini` 항목은 스펙트럼·음량 분석 방식으로 구한 값을 바탕으로 합니다. 음원 이름에 해석하기 어려운 표기가 있거나 같은 모음이 연속되어 경계를 찾기 어려운 경우에는 신뢰도가 낮아질 수 있습니다. 신뢰도는 추정 결과가 정확할 확률을 나타내는 값이 아닙니다. 원음 설정 편집기에서 추정 결과를 확인하고 필요에 따라 수동으로 조정해 주세요.

## 다운로드

배포 파일은 [GitHub Releases](https://github.com/abschan-dayo/UTAU-Oto-Automation/releases)에서 받을 수 있습니다.

- **Windows CPU 버전**: `Autoto-CPU.exe`. CPU로 동작합니다.
- **Windows CUDA 버전**: `Autoto-CUDA.exe`. 지원되는 NVIDIA GPU와 드라이버가 있으면 GPU를 사용합니다. CUDA를 사용할 수 없으면 알림을 표시한 뒤 CPU로 전환합니다.
- **macOS 버전**: `Autoto.dmg`. Apple Silicon(arm64) 전용이며 Intel Mac은 지원하지 않습니다.

### macOS 설치

1. `Autoto.dmg`를 엽니다.
2. 표시된 `Autoto.app`을 Applications 폴더로 드래그합니다.
3. Applications에서 `Autoto.app`을 실행합니다.

Developer ID 서명과 Apple 공증은 아직 진행하지 않았습니다. macOS에서 보안 확인 메시지가 표시될 수 있습니다.

## 사용 방법

1. CPU 또는 CUDA 실행 파일을 실행하거나 Applications에 복사한 `Autoto.app`을 실행합니다.
2. **폴더 선택**을 눌러 WAV가 들어 있는 음원 폴더를 지정합니다. 창으로 폴더를 드래그해 지정할 수도 있습니다.
3. 사용할 분석 방법을 하나 이상 선택하고 **분석 시작**을 누릅니다.
4. 분석이 끝나면 음원 폴더의 `oto.ini`를 원음 설정 편집기에서 확인하고 필요한 부분을 직접 조정합니다.

저장 동작에 대한 자세한 내용은 [사용 방법 및 덮어쓰기 설명](docs/使い方.md)을 참조하세요.

## vLabeler 연동 및 Heartbeat

분석이 완료되면 vLabeler에서 편집을 계속할지 묻는 메시지가 표시됩니다. **예**를 선택하면 vLabeler가 실행되고 생성된 `oto.ini`가 열립니다. 처음 사용하거나 등록된 경로에서 vLabeler를 찾을 수 없는 경우에는 Windows에서 `vLabeler.exe`를, macOS에서 `vLabeler.app`을 선택해 주세요. 선택한 경로는 다음 실행 시 사용할 수 있도록 저장됩니다.

로컬 설정 파일에는 선택한 vLabeler 실행 파일 또는 앱의 경로만 저장됩니다. Windows 경로는 `%LOCALAPPDATA%\UTAU原音設定自動化ツール\設定.json`이며, macOS 경로는 `~/Library/Application Support/UTAU原音設定自動化ツール/設定.json`입니다.

Autoto는 vLabeler의 Heartbeat 통신을 통해 실행 여부와 응답 상태를 확인합니다. vLabeler가 실행 중이 아니면 실행을 시도하고, 응답을 받은 뒤 음원 폴더와 생성된 원음 설정을 열도록 요청합니다. 여기서 Heartbeat는 앱 간에 응답 여부를 확인하는 기능이며, 재생 위치를 따라가는 기능은 아닙니다. vLabeler 자체는 Autoto에 포함되어 있지 않습니다.

## `oto.ini` 저장 및 백업

- `oto.ini`가 없으면 새로 만듭니다.
- 기존 `oto.ini`가 있으면 분석을 시작하기 전에 덮어쓸지 묻는 메시지가 표시됩니다. **예**를 선택하면 기존 파일을 덮어씁니다. **아니요**를 선택해도 분석은 진행되며, 음원 폴더의 상위 폴더에 새 `生成済み` 폴더를 만들어 `oto.ini`를 저장합니다. 취소를 선택하면 분석을 시작하지 않습니다.
- 처음 덮어쓸 때 기존 `oto.ini`를 `oto_backup.ini`로 저장합니다. 이미 `oto_backup.ini`가 있으면 그대로 보존합니다.
- 분석 중 `oto.ini`가 변경되면 해당 변경 사항을 덮어쓰지 않도록 저장을 취소합니다.

결과가 저장된 폴더에 `Autoto_クレジットについて.txt`를 생성하여 공개·배포 시의 크레딧 조건을 안내합니다. 같은 이름의 안내 파일이 이미 있으면 그대로 보존합니다.

## 진행 상황 및 로그

WAV 읽기, 특징 추출, 경계 분석은 WAV별로 병렬 진행되므로 하나의 진행 항목으로 표시됩니다. 각 단계가 끝나면 녹색 체크 표시가 나타납니다. 저장이 완료되면 **결과 확인**을 눌러 결과를 볼 수 있습니다.

작업 로그는 음원 폴더 안의 `キャッシュ/ログ`에 저장되며, 파일명에는 작업명과 날짜·시간이 포함됩니다. **로그 열기**로 이번 작업의 로그를 확인할 수 있습니다. 앱 버전과 빌드 식별자, 사용한 GPU, 분석 방법별 실행 장치와 소요 시간, 입력 형식과 변환 건수, 성공·실패 건수, 추정값 채택 및 대체 건수를 기록합니다. 캐시를 삭제해도 로그는 보존됩니다. 음원 폴더나 저장 위치의 절대 경로, 예외 메시지 본문, 트레이스백은 로그에 기록하지 않습니다. 이전 버전의 AppData 로그는 링크나 로그 이외의 파일이 없고 일반 권한으로 삭제할 수 있는 경우에만 정리합니다.

## 입력 오디오

분석을 시작하기 전에 입력 WAV 처리 방법을 선택할 수 있습니다. 입력 파일을 표준 형식으로 일괄 변환하지 않고 분석하거나, 메모리상에서 44.1 kHz, 16비트 상당, 모노로 변환하여 분석할 수 있습니다. 어느 방법을 선택해도 `oto.ini`를 생성할 수 있으며 원본 WAV 파일은 변경하지 않습니다. 변환을 선택하지 않아도 고정 입력 형식이 필요한 모델 기반 방식은 필요에 따라 내부에서 44.1 kHz로 리샘플링합니다. 스테레오 음성은 분석을 위해 메모리상에서 모노로 다운믹스합니다.

## 동작 확인 및 주의 사항

- Windows CUDA 버전은 Ampere 세대 GPU에서 동작을 확인했습니다. Blackwell 세대를 포함한 다른 GPU 구성에서는 아직 동작을 확인하지 않았습니다.
- macOS 버전은 Apple Silicon용입니다. macOS 26.6.1에서 DMG 검증과 마운트, 분석 처리를 확인했습니다. GUI 화면을 직접 조작하는 방식으로는 아직 동작을 확인하지 않았습니다.
- 신뢰도는 내부 추정 지표입니다. 앱 화면에 표시되지 않으며 정확도를 나타내지도 않습니다. 생성 결과를 반드시 확인해 주세요.
- 베타 버전입니다. OS, GPU, 드라이버에 따라 동작이 다를 수 있습니다.

## 데이터 및 개인정보 보호

실제 음원 이름, 개인 환경의 파일 경로, 원본 WAV, 기존 `oto.ini`와 추정 결과 또는 수동 수정 결과가 담긴 `oto.ini`, 학습 데이터는 이 저장소에 포함하지 않습니다. 개인정보나 음원 정보를 GitHub Issue 또는 Pull Request에 포함하지 마세요.

향후 정확도 개선 및 검증을 위해 `推定後_oto.ini`와 `手動修正後_oto.ini`를 자발적으로 제공해 주실 분을 모집할 수 있습니다. 제출 방법, 이용 목적, 보관 기간, 삭제 요청 방법을 명시한 모집 안내가 게시되기 전까지는 설정 파일을 보내지 마세요. 원본 WAV 파일의 제공은 요청하지 않습니다.
