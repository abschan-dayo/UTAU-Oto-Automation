# Windows版の使い方

1. GitHub Releases から Windows CPU版のZIPを取得し、展開します。CUDA単体版を使う場合はCUDA用EXEを取得します。CUDA版にはNVIDIA GPUと対応ドライバーが必要です。
2. CPU版は `UTAU原音設定ツール_CPU.exe`、CUDA単体版はダウンロードしたCUDA用EXEを起動します。
3. 「フォルダを選択」で解析対象の音源フォルダを選びます。フォルダにはWAVを直接入れてください。
4. 使用する推定方式を選び、解析を開始します。解析が終わると `推定後_oto.ini` が音源フォルダに保存されます。
5. 結果を確認し、必要に応じて原音設定エディタなどで調整してください。

入力WAVの標準形式は44.1 kHz・16 bit・モノラルPCMです。ファイル名には解析可能なかなの録音列が必要です。元WAVと既存の `oto.ini` は変更しません。

既存の `推定後_oto.ini` があるときは、画面で上書きするかを選べます。上書き前の推定結果は、初回のみ `推定後_oto_backup.ini` に保存します。手動で調整した設定を上書きしないよう、必要なファイルは別名で保存してください。

解析結果に含まれる「推定信頼度」は、推定器の根拠の明確さを表す自己診断値であり、正解率ではありません。

動作しない場合は、CPU版とCUDAフォルダ版ではZIP内のフォルダ構成を保ったまま展開したか確認してください。この2方式ではEXEと `_internal` フォルダが同じ場所に必要です。CUDAフォルダ版では3つのZIPをすべて統合したか確認してください。CUDA単体版には `_internal` フォルダは不要です。どちらのCUDA版でもNVIDIAのドライバーが利用可能か確認してください。
