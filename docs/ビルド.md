# 自動推定ツールのビルド

このリポジトリには自動推定ツールの操作画面・保存処理と推定アルゴリズムのソースが含まれます。手動編集用の原音設定エディタのソースは含まれません。利用条件は `LICENSE`、各配布物の通知文、および [CUDA単体版の第三者ソフトウェア通知](THIRD_PARTY_NOTICES_CUDA_SINGLE.md) を参照してください。

## 準備

WindowsのPython 3.12環境を用意し、`algorithm/requirements.txt` の依存物のほか、`tkinterdnd2`、`pyzmq`、PyInstallerをインストールします。CPU版はPyTorch 2.6.0+cpu、従来のフォルダ形式CUDA版はPyTorch 2.8.0+cu128を使用しました。共通のビルド環境ではtkinterdnd2 0.6.3、pyzmq 27.2.0、PyInstaller 6.22.3を使用しました。PyTorch環境は方式ごとに分けてください。

学習済みモデルはGitリポジトリに含みません。公式Releaseの配布ZIPにある `_internal/models/` の4ファイルを、ローカルの `algorithm/models/` にコピーしてください。WAV、oto.ini、実際の音源名や個人パスをビルド元に入れないでください。`models/` は `.gitignore` の対象です。

## フォルダ形式

`algorithm/` で次を実行します。

```powershell
python -m PyInstaller --noconfirm --windowed --onedir --name Autoto-CPU --add-data "models;models" --collect-all tkinterdnd2 v1_oto.pyw
```

CUDA版は `build_cuda_single.py --reference-exe "<EXISTING_CUDA_EXE>"` で再構築します。出力名は `Autoto-CUDA.exe` です。CUDA依存DLLとモデル抽出のため、参照EXEとCUDA用Python環境が必要です。

実際のRelease用パッケージでは、パッケージに含まれる第三者ライセンス文、通知文、モデルの一致、不要な見本データの混入を別途確認します。ローカルの個人パスを含むビルドログや `.spec` ファイルは公開しないでください。

## 軽量CUDA単体EXE

## CPU版を単体EXEにする

CPU版もPyInstallerの `--onefile` で単体EXEにできます。起動時に内容を一時フォルダーへ展開するため、起動はフォルダー版より遅くなり、EXEサイズも大きくなります。CUDA版よりは小さいものの、PyTorchと科学計算ライブラリを含むため数百MB規模です。

Windows Python 3.12で `algorithm/requirements.txt`、CPU専用PyTorch 2.6.0、`tkinterdnd2` 0.6.3、`pyzmq` 27.2.0、PyInstallerを用意し、4つのモデルファイルを `algorithm/models/` に置いてから、リポジトリのルートで実行します。

```powershell
python build_cpu_single.py
```

出力先は `dist-cpu-single/Autoto-CPU.exe` です。モデルと依存パッケージが存在しない現在の公開ソースだけでは、このEXEを再生成できません。

PyTorchのCUDA版を丸ごと収録すると単体EXEが3 GiBを超えます。軽量構成は、PyTorch CPU版で画像モデルを実行し、CuPyで波形のFFTと自己相関をGPU上で計算します。これにより単体EXEの試作サイズを約768 MiBに抑え、合成WAVの全方式による解析が完了しました。同じ合成WAVで、従来CUDA版と設定値の出力がバイト単位で一致しました。CUDA開発環境の検索パスを外した状態で、単体EXEのGPU推定も完了しました。実音源での精度や、手元以外のGPUでの動作は未確認です。

軽量構成はPyTorch 2.6.0+cpu、CuPy CUDA 12.x版 13.5.1、fastrlock 0.8.3を使用します。`build_cuda_single.py` は公式EXEから公開用の4モデルとCUDA 12.8系の実行DLLを取り出し、同じ版を再構築します。ビルドログ、生成された `.spec`、抽出されたモデル・DLLはGitに含めないでください。

```powershell
python build_cuda_single.py --reference-exe "<OFFICIAL_CUDA_EXE>"
```

この方式では画像モデルの推定はCPUで実行します。CuPy側のGPU計算が失敗した場合、`--device cuda` 指定はエラーとして扱います。公開配布に使う際は、第三者ライセンス通知、DLLとモデルの来歴、EXE内の個人パス・不要なデータの混入を確認してください。LGPL適用ライブラリを改変して組み合わせる場合も、このソースとビルド手順を使用できます。
