# 配布物と第三者ソフトウェア

Windows CPU版のZIPには、EXE、動作に必要なライブラリ、公開用に個人データの来歴ハッシュを除いた推定モデル、利用条件、第三者ライセンス文を含めます。EXEと `_internal` フォルダを離さずに展開してください。

NumPy、SciPy、SoundFile、librosa、PyWorld、Matplotlib、scikit-learn、joblib、PyTorch、tkinterdnd2などの第三者ソフトウェアを利用します。各ライセンスは独自コードの `LICENSE` とは別に適用されます。配布ZIPの `THIRD_PARTY_NOTICES.md` と `THIRD_PARTY_LICENSES/` に採用版の通知文を収録します。

SoundFile に含まれる libsndfile と、librosa 経由で利用する Python-SoXR には LGPL の条件が含まれます。配布ZIPではライブラリを `_internal` 以下の個別ファイルとして置き、利用者が該当ライブラリを差し替えられる構成にします。対応ソースの入手先は `THIRD_PARTY_NOTICES.md` を参照してください。

CUDA単体版はEXEの中に動作ライブラリと公開用モデルを含めます。起動時に一時フォルダへ展開する方式です。単体版の第三者ライセンス文は、GitHub Releasesの同じバージョンにある `cuda-single-licenses.zip` と通知文を参照してください。CuPy、fastrlock、NVIDIA CUDA 12.8系DLLの条件も含まれます。LGPL適用ライブラリを変更して組み合わせるための公開ソースとビルド手順は `build_cuda_single.py` および [ビルド](ビルド.md) にあります。
