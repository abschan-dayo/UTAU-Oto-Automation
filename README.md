# UTAU原音設定自動化ツール（Autoto）

WAVからUTAU音源の原音設定を自動推定します。推定結果は音源フォルダーの `oto.ini` に保存します。

## ダウンロード

配布ファイルは[GitHub Releases](https://github.com/abschan-dayo/UTAU-Oto-Automation/releases)から取得してください。

- **Windows CPU版**: `Autoto-CPU.exe`。CPUで動作する単体版です。
- **Windows CUDA版**: `Autoto-CUDA.exe`。対応するNVIDIA GPUとドライバーがある場合にGPUを使います。CUDAが利用できない場合は通知を出してCPUに切り替えます。
- **macOS版**: `Autoto.dmg`。Apple Silicon（arm64）専用です。Intel Macには対応していません。

### macOSへのインストール

1. `Autoto.dmg` を開きます。
2. 表示された `Autoto.app` をApplicationsフォルダーへドラッグします。
3. Applicationsから `Autoto.app` を起動します。

Developer ID署名とApple公証は未実施です。macOSのセキュリティ確認が表示される場合があります。

## 使い方

1. CPU版またはCUDA版のEXE、あるいはApplicationsに入れた `Autoto.app` を起動します。
2. WAVが入った音源フォルダーを「フォルダーを選択」で指定します。画面へフォルダーをドラッグして指定することもできます。
3. 使用する解析方式を1つ以上選び、「解析を開始」を押します。
4. 完了後、音源フォルダー内の `oto.ini` を原音設定エディタで確認し、必要な箇所を手動で調整します。

詳しい保存動作は[使い方と上書きの説明](docs/使い方.md)を参照してください。

## `oto.ini` の保存とバックアップ

- `oto.ini` がまだない場合は、新しく作成します。
- 既存の `oto.ini` がある場合は、解析開始前に上書き確認を表示します。「はい」で置き換え、「いいえ」またはキャンセルで処理を中止します。
- 初回の上書き時に、元の `oto.ini` を `oto_backup.ini` として保存します。すでに `oto_backup.ini` がある場合は保持します。
- 解析中に `oto.ini` が変更された場合、その変更を上書きしないよう保存を中止します。

## 入力音声

解析時にWAVを44.1 kHz・16 bit相当・モノラルへメモリ上で変換します。変換が必要な場合は通知します。元のWAVファイルは変更しません。

## 動作確認と注意

- Windows CUDA版はRTX 3080で動作確認済みです。RTX 5060（Blackwell）を含むほかのGPU構成は未確認です。
- macOS版はApple Silicon向けです。macOS 26.6.1でDMGの検証・マウントと解析処理を確認しました。GUI画面の操作確認は未実施です。
- 画面に表示する信頼度は推定の曖昧さを示す参考値で、正解率ではありません。生成結果を必ず確認してください。
- これはベータ版です。OSやGPU、ドライバーによって動作が異なる場合があります。

## データとプライバシー

実音源名、個人パス、原音WAV、既存・推定後・手動修正後の `oto.ini`、学習データはこのリポジトリに含めません。個人情報や音源情報をGitHubのIssueやPull Requestに含めないでください。

将来、精度改善・検証のため `推定後_oto.ini` と `手動修正後_oto.ini` の任意提供を募集する場合があります。提供方法、利用目的、保存期間、削除依頼方法を明記した募集を行うまでは、設定ファイルを送らないでください。原音WAVの提供は求めません。

## ソースとライセンス

`algorithm/` に原音設定推定アルゴリズムとアプリの処理コードを含みます。原音設定エディタのソースコードは含みません。この制作ではCodexを主に使用しています。
