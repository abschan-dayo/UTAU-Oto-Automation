# UTAU原音設定自動化ツール

配布名: Windows CPU `Autoto-CPU.exe` / Windows CUDA `Autoto-CUDA.exe` / Apple Silicon `Autoto.app`。

WAVからUTAU音源の原音設定を自動推定します。結果は音源フォルダーの `oto.ini` に保存します。既存の `oto.ini` を置き換える場合は確認を表示し、初回に限り元ファイルを `oto_backup.ini` に退避します。

ベータ版です。推定結果を確認し、必要に応じて調整してください。表示される信頼度は正解率ではありません。

## 配布物

ReleaseではWindows CPU版、Windows CUDA版、macOS Apple Silicon版を配布します。対応OSや動作確認状況はReleaseの説明と[使い方](docs/使い方.md)を確認してください。

## ソース

`algorithm/` に推定アルゴリズムと実行・保存処理を含みます。手動編集用の原音設定エディタのソースコードは含みません。ビルド手順は[ビルド説明](docs/ビルド.md)を参照してください。

## データ

実音源名、個人パス、原音WAV、既存・推定後・手動修正後のoto.ini、学習データはこのリポジトリに含めません。個人情報や音源情報をIssueやPull Requestに含めないでください。

将来、精度改善・検証のため、`推定後_oto.ini` と `手動修正後_oto.ini` の任意提供を受け付ける場合があります。提供方法・利用目的・保存期間・削除依頼方法を明記するまでは、設定ファイルを送らないでください。原音WAVの提供は求めません。
