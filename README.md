# UTAU原音設定自動化ツール

WAVを解析し、UTAU音源向けの原音設定を自動推定するツールです。推定結果は `推定後_oto.ini` に保存します。既存の `oto.ini` は入力として読み取りますが、直接書き換えません。上書き時は確認し、既存の推定結果をバックアップします。

このツールはベータ版です。推定結果と信頼度を必ず確認し、必要に応じて原音設定エディタで修正してください。信頼度は正解率を示すものではありません。

## 配布版

配布ファイルと対応する説明は [GitHub Releases](https://github.com/abschan-dayo/UTAU-Oto-Automation/releases) に掲載します。

| 配布版 | 対象 | 解析 | 確認状況 |
| --- | --- | --- | --- |
| Windows CPU版 | Windows x64 | CPU | 配布ZIP内の説明を参照 |
| Windows CUDA単体版 | Windows x64、NVIDIA GPU | CUDAで一部処理 | RTX 3080で確認。RTX 5060は未確認 |
| macOS版 0.2.0-beta5 | Apple Silicon（arm64） | CPU | macOS 26.6.1でGUI起動と合成音声による3方式を確認 |

macOS版はDeveloper ID署名とApple公証を行っていません。macOSのセキュリティ警告が表示される場合があります。実音源での精度や、記載したもの以外のOS・GPU環境は未確認です。Windows版とmacOS版はバージョンが異なります。

## ソースの範囲

`algorithm/` には原音設定の解析アルゴリズムと、その実行・保存処理が含まれます。学習済みモデルや音源データはソースリポジトリに含めず、配布版に必要な範囲で同梱します。原音設定エディタのソースコードは含めません。配布用アプリはReleaseから取得してください。

## データとプライバシー

原音WAV、実音源名、既存・推定後・手動修正後のoto.ini、学習データはこのリポジトリに含めません。個人のパスや音源情報をIssueやPull Requestに書かないでください。

将来、推定精度の改善・検証のため、`推定後_oto.ini` と `手動修正後_oto.ini` の任意提供を受け付ける場合があります。提供方法・利用目的・保存期間・削除依頼方法を明記するまでは、設定ファイルを送らないでください。原音WAVの提供は求めません。
