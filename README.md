# UTAU 原音設定自動化ツール

UTAU 音源の原音設定を推定する Windows 向けツールです。入力WAVを解析し、結果を音源フォルダの `推定後_oto.ini` に書き出します。既存の `oto.ini` は変更しません。

このリポジトリには推定アルゴリズム、自動推定ツールの操作画面と保存処理のソース、使い方、利用条件を置いています。原音設定エディタのソース、学習元の音源・設定ファイル、学習済みモデルは含めていません。配布用EXEは、このリポジトリの **Releases** から提供します。

## 使い方

Windows CPU版はReleasesのCPU用ZIPを展開し、`UTAU原音設定ツール_CPU.exe` を起動してください。NVIDIA GPU向けにはCUDA単体EXEを用意しています。CUDA版はGPUが使えない場合にCPUへ切り替えず、エラーをログに記録します。RTX 3080で確認済みですが、RTX 5060では未検証です。画面で音源フォルダを選び、推定方式を選択して解析します。詳しくは [使い方](docs/使い方.md) を参照してください。

入力は44.1 kHz・16 bit・モノラルPCMのWAVを基本とします。方式によっては左右のPCMデータが完全に同じステレオWAVも扱えます。ファイル名から音素列を特定できない場合は解析を中止します。

同じフォルダに `推定後_oto.ini` がある場合、明示的に上書きを選択しない限り置き換えません。上書き時には、初回だけ旧推定結果を `推定後_oto_backup.ini` に保存します。

## ソースコード

`algorithm/` に推定処理、CLI、Windows版の自動推定操作画面を置いています。学習済みモデルはこのソース配布に含みません。原音設定エディタのソースは公開していません。軽量CUDA単体版はCuPyで波形のFFTと自己相関をGPU実行し、画像モデルはCPU実行します。実行方法は [algorithm/README.md](algorithm/README.md)、ビルド方法は [ビルド](docs/ビルド.md) を参照してください。

## 利用条件

独自コードの著作権者は **ふっきんちゃん** です。未確定要素が多いため、推定精度向上を主な目的とする改変版の再配布のみ認めます。公式EXEの無改変再配布は認めません。詳しくは [LICENSE](LICENSE) を参照してください。これは標準オープンソースライセンスではありません。

第三者ライブラリには各ライセンスが適用されます。配布ZIPには各ライセンス文と対応ソースの案内を同梱します。

## 改善への協力

将来、希望する利用者から `推定後_oto.ini` と `手動修正後_oto.ini` の組を任意で受け取り、精度改善と検証に使う仕組みを検討しています。提供方法、利用目的、保存期間、削除依頼方法を定めるまでは、設定ファイルを送らないでください。原音WAVの提供は求めません。Issueにも音源名・WAV・oto.ini・個人のパスを掲載しないでください。
